# Product Card Webpage

A clean,  HTML and CSS implementation of a responsive product card component featuring a fixed navigation bar, discount badge, image hover effect, and stock alert indicator.

## Features

- **Fixed Top Navigation Bar:** Stays pinned to the top of the viewport while scrolling.
- **Product Card Component:** Includes an image container with a hover zoom effect, text description, price comparison, and two action buttons.
- **Positioned Badge:** Uses absolute positioning to layer a discount tag over the card image corner.
- **Responsive Layout:** Centered layout structured with basic CSS property rules.
